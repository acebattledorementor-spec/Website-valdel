## 4. Conversion: CTAs and forms

**CTA set (use consistently):** *Send a tender package* (primary, everywhere) · *Request pre-bid support* ·
*Download capability statement* · *Get the prequalification pack* · *Talk to an engineer* · *Apply*.

- Required (keep to 4): name, company, business e-mail, message.
- Optional: asset type, service(s), region, end user, bid due date, project timeline, estimated scope (man-hours or
  deliverables), "NDA required before sharing documents" tick, **file upload** (PDF, DWG, DXF, XLSX, DOCX, ZIP; up to
  100 MB; or a link to the client's share).
- After submitting: a confirmation page with the response commitment ("A VDE engineer replies within 1 working day"
  **[CONFIRM]**), the BD contact's name, and a calendar link for a call.
- If NDA is ticked, the auto-reply includes VDE's mutual NDA template.

**Lead routing & CRM:**
- Each submission e-mails the BD team and is stored in the form back-end.
- **Valdel One integration (internal system, not on the internet):** never expose Valdel One to the web. Export new leads
  daily or weekly as an `.xlsx` with these exact columns, ready to drop into Valdel One's `data/mi_inbox/` lead inbox:
  `Lead ID, Found Date, Category, End User, EPC / Contractor, Project, Scope, Facility, Location, Region, Sector, Service,
  Est Value USD, Timeline, Project Status, Suggested Class, Fit Rating, Competition Rating, Location Rating,
  Resource Rating, MI Ref, Participants, Awarded To, Market Award Date, Key Person, Engineering SOW, VDE Angle,
  Source Link, Source Date, Status, BDOS Opp ID, Reviewed On`
  (Category = "Website enquiry"; Source Link = page URL; unknown fields left blank). BD accepts or dismisses each lead
  in Valdel One, which then opens the opportunity → RFQ → Gate-1 chain.
- Optional: HubSpot / Zoho CRM free tier, if VDE adopts one **[CONFIRM]**.

**Analytics:** privacy-friendly analytics (Plausible, Matomo or GA4 with consent mode). Track these events:
tender_form_start / submit, prebid_form_submit, file_upload, download_capability, download_prequal, job_apply,
email_click, phone_click, case_study_view, filter_used, search_query, and 50% / 90% scroll on case studies.

**Downloads:** the capability statement (PDF, ≤ 3 MB) is ungated. The prequalification pack is gated by e-mail only,

## 6. Performance, SEO and technical foundation

**Stack:** a static-first site (Astro, Eleventy or Next.js static export) with a headless CMS or Markdown content
(Decap, Sanity or Strapi) so BD / marketing can add projects and jobs without a developer. No heavy page builders.
Hosted on a CDN (Cloudflare Pages, Netlify or Vercel) or Indian hosting with a CDN in front.

**Performance budget:** LCP < 2.5 s and INP < 200 ms on 4G mobile; CLS < 0.1; total JS < 100 KB on content pages.
Images: AVIF / WebP, responsive `srcset`, lazy-loaded below the fold. Hero video: H.264 + WebM, ≤ 4 MB, poster first,
no autoplay on mobile data-saver. Fonts: subset WOFF2 with `font-display: swap`. Lighthouse score ≥ 95 on all four
categories.

**SEO:**
- One page per asset, service and discipline, each targeting a clear phrase, e.g. "offshore jacket design engineering
  India", "wellhead platform engineering services", "SACS in-place and fatigue analysis", "FPSO topside module
  engineering", "subsea pipeline on-bottom stability design", "offshore substation jacket design", "pre-bid engineering
  support for EPC tenders", "as-built drawings and 3D model offshore", "offshore weight control services".
- Location and market terms where VDE works: Bengaluru / India, Middle East (Saudi Arabia, Qatar, UAE), South Korea,
  Southeast Asia (Thailand, Malaysia, Indonesia, Brunei), the Caribbean **[CONFIRM markets]**.
- Unique title (≤ 60 characters) and meta description (≤ 155 characters) on every page; one H1; descriptive URLs;
  internal links between asset ↔ service ↔ project; XML sitemap; robots.txt; canonical tags; Open Graph / LinkedIn
  preview images.
- Schema.org: Organization (logo, address, contactPoint, sameAs LinkedIn), ProfessionalService, Service for each
  service, CreativeWork / Article for case studies, JobPosting for jobs, BreadcrumbList, FAQPage on asset pages.
- A Google Business Profile for the Bengaluru office **[ADD]**.

**Security & compliance:**
- HTTPS only with HSTS; a security header set (CSP, X-Content-Type-Options, Referrer-Policy, Permissions-Policy).
- Forms: server-side validation, Cloudflare Turnstile or hCaptcha plus a honeypot, and rate limiting. File uploads are
  virus-scanned, stored privately (not publicly linkable), auto-deleted after 90 days **[CONFIRM]**, and only BD can
  access them.
- **Privacy notice under India's DPDP Act 2023:** what is collected (enquiry and CV data), why, how long it is kept, and
  the grievance officer's contact **[ADD]**. Cookie consent banner (no non-essential cookies before consent). An NDA /
  confidentiality statement on the tender form.
- Accessibility: WCAG 2.2 AA – keyboard navigation, visible focus, labelled form fields, alt text, captions on
  videos.
- Backups, uptime monitoring and a named owner for updates.
