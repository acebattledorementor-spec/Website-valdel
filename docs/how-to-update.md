# How to update the VDE website

**Where:** go to `https://<website>/admin`, sign in with your GitHub account. Every change is saved as a draft;
a reviewer clicks **Publish**, and the live site updates in about two minutes.

## Add a project (case study)

1. **Projects → New Project.**
2. Fill in the *anonymised title* first (e.g. "Detail engineering of 10 jackets, Middle East"). It is what the
   public sees until a client permission box is ticked.
3. Fill in the full title, EPC client and end user. **Tick "Written permission" only when you have it in
   writing.** Without the tick, the site shows "Offshore EPC contractor" instead.
4. Choose asset types, services and disciplines: these drive the filters, the capability matrix and the
   "related projects" on other pages.
5. Write the **Challenge** (2–3 sentences) and the **Engineering approach** (bullets). Fact-panel numbers
   (water depth, tonnage, man-hours) are real figures only; leave one empty and it is not shown.
6. Images: real VDE work only (model renders, drawings with client permission). No stock photos, no
   AI-generated images. Every image needs alt text and a caption.
7. Leave **Publish** off until the project lead has checked the text, then turn it on.

## Add a job

**Open positions → New Position.** Use the position code from the HR requisition. Set a closing date: the job
disappears from the site automatically after it. Applicants e-mail hrblr@valdelec.com with the code in the
subject, or use the form (CVs go to HR only, never into BD records).

## Update company facts

**Company facts & documents → Company facts.**

- **Counters** on the home page: update the value and the "as of" month. Tick *confirmed* only when the figure
  is approved for publication.
- **Clients:** a name or logo is shown only when *permission* is ticked.
- **Certificates:** add issuer, number and expiry (YYYY-MM-DD). Expired certificates hide automatically.
  Upload the renewed certificate before expiry.
- **Prequalification pack:** never uploaded to the website. Requests arrive in the BD inbox (subject
  "Prequalification pack request"); BD replies with the current pack by e-mail.

## Add a news item or technical note

**Insights / news → New Article.** Title, date, a one-line summary (≤ 155 characters) and the body. Keep it
factual: what was done, for whom (with permission), and the result.

## Rules that keep the site trustworthy

- No client name, logo, figure or photo without written permission.
- No buzzwords ("world-class", "cutting-edge", "one-stop solution"). Short sentences. Every claim has a fact or a
  link.
- If a change looks wrong after publishing, open the item and publish the previous text again, or ask the web
  administrator to roll back (every version is kept in Git).

## Weekly: website leads into Valdel One

Every Monday a scheduled task copies the week's website enquiries into Valdel One's Market Intelligence
inbox. In Valdel One, open **Market Intelligence**, then **Accept** (opens a pre-filled opportunity) or
**Dismiss** each lead marked *Website enquiry*.
